## Backlog note

Moved verbatim from this task's row in [`BACKLOG.md`](BACKLOG.md)
by task `BL-119` (2026-11-01); the row links here.

Rules are indexed by advisory id (`indexRulesByVulnerabilityId`, `rule-loader.ts`), and a duplicate id is a usage error (exit 2, measured). Since B-6 a rule applies only to the package it names, so the other package of a multi-package advisory can only ever be `UNKNOWN` (`rule_package_mismatch`), never `AFFECTED`. Needs a design decision (SDD § 13 rule format: key by id and package, or several targets per rule); coverage and precision, no false `NOT_AFFECTED`
