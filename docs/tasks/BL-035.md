Closes RWF-058. `@make(arg()) m() {}`: `arg()` runs at class definition, but the walk reaches it under the member `m`, so the graph records `m → arg` (a misattributed edge; the decorator's own account, from the class-definition owner, is unknown, so no negative proof is manufactured). RWF-023 fixed the same shape for a member's computed key by adding the class-definition-time edge and keeping the member's; the same approach applies here. Explainability: an `AFFECTED` path through such a decorator names the wrong caller.
