## Backlog note

Discovered in `BL-113`, which measured it (task file, "Account"). No rule
of BL-075, BL-081, BL-091 or BL-110 exists only for a change to a
built-in prototype, but three parts of rules do, in the code that decides
them and in every oracle case that tests them:

- BL-075 (RWF-112): `C instanceof E` is not inert for a plain-object `E`;
- BL-081: iterating an array literal or a string adds an unknown edge
  (`cost.for-of-primitives`);
- BL-110: most of the escape side of the `module.paths` allow-list
  (spread, conversions, non-mutating methods, `for…of`).

BL-081's and BL-110's parts guard only a `NOT_AFFECTED` (an unknown edge,
an incomplete closure): under the boundary each costs precision for no
soundness benefit, unless a route the boundary does not cover reaches it.
BL-075's part guards an export attribution, which the boundary does not
condition (SOUNDNESS-CONTRACT § 1, "What it is not"): narrowing it waits
for `BL-122`, and a route outside the boundary (a derived-class or
async-function `E`) is not established either way. The decision record
withdraws no rule: narrowing any needs the owner's decision and a
measurement (`scripts/measure-options.mjs`).
