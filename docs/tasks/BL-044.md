## Backlog note

Moved verbatim from this task's row in [`BACKLOG.md`](BACKLOG.md)
by task `BL-119` (2026-11-01); the row links here.

With `importHelpers` and a downlevel `target`, TypeScript compiles object spread, async functions, decorators and similar constructs to `require("tslib")`; nothing in `src/` models it, so a `tslib` advisory may get a family-A `NOT_AFFECTED` while Node loads `tslib` -- the same shape as RWF-066. Reproduce against real Node (oracle harness), then register a finding and a lane-C fix row if it reproduces.
