## Backlog note

Moved verbatim from this task's row in [`BACKLOG.md`](BACKLOG.md)
by task `BL-119` (2026-11-01); the row links here.

Performance, not soundness, but a crafted dependency can stall a scan. Both are pre-existing on the base. (1) `resolveLoaderCapability` follows every selectable operand of a `const` alias without memoization: `const a0 = 0;` then ten lines of `const a{i+1} = a{i} || a{i} || a{i};` (290 bytes) took 9.5 s on the base and ~×3 per added line. BL-110's use check, which resolves every identifier, makes it about 1.5× the base. Fix direction: memoize a resolution per node within a pass, measured structurally. (2) A `||` chain of about 1,500 terms overflows Node's default stack in TypeScript's own recursive walks (`forEachChild`, `constDeclarationsOf`). Whether the scanner reports that as `UNKNOWN` or crashes is not established; measure it first. Fail-closed is required
