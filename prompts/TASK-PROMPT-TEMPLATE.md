Before coding:

- read AGENTS.md;
- read the SDD sections referenced by the task;
- inspect current code;
- identify existing abstractions to reuse.

- keep the change scoped;

- avoid target-code execution.

- run typecheck;
- run tests;
- run lint/format if configured;
- verify every acceptance criterion.

Report:

- implementation;
- files changed;
- tests;
- results;
- limitations.
