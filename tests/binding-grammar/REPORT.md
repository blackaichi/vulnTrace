| `array-element-named-sibling` | index | single-valued | Index 1, with an EXPORTED name sitting at index 0. A first-match walk over the pattern's names reaches `run` and attributes the call to the sibling; the correct answer names position 1. |
| `rest-in-array` | nothing | never-callable: an array rest binds an ARRAY of the remaining elements | The array twin of `rest-in-object`, and the shape RWF-046a's own note says a 'not an array pattern' gate would have missed. |
| `object-in-array` | property-of-index | single-valued | The real path is `A[0].run`. Where a mechanism supplies an array, the fixture's element 0 is an object holding a DISTINCT callable, so dropping either hop is visible. |

| mechanism | owner | note |
| --- | --- | --- |
| `direct-call` | RWF-043 / P1-B3b | The mechanism RWF-043 corrected: a bare-identifier call whose callee is a same-file declaration. Everything here is local, so a wrong answer is a wrong DECLARATION rather than a wrong install. |
| `require-provenance` | RWF-046 / RWF-046a | The only mechanism swept before this instrument existed. The binding is initialized directly from `require("literal")`, which is the path `resolveImportProvenanceDeclaration` owns. |
| `destructuring-bridge` | RWF-045 | One hop further out than the require column: the initializer is a plain identifier that is itself a module binding, which is the bridge RWF-045 rebuilt on binding-element identity. |
| `higher-order-parameter` | VT-210 | The row's binding becomes the ARGUMENT at `invoke`'s single call site, and the observed edge is the one leaving `invoke` itself. | `esm-import` | SDD § 17 | The ESM half of the convergence SDD § 17 requires: `import { v } from 'foo'; v()` and `const { v } = require('foo'); v()` must reach the same target. A namespace object is not iterable, so array patterns over it have no correct target. |
